## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ANANDRAJ012/food-delivery.git
   ```

2. Navigate to the project folder:
   ```bash
   cd food-delivery
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the project locally:
   ```bash
   npm start
   ```
